# Space Mission: Moon Landing (JavaFX Game)

Game 2D berbasis JavaFX dengan konsep roket meluncur menghindari asteroid hingga mencapai skor 5000 untuk mendarat di Bulan dan menancapkan bendera.

## Fitur Game
- Main Menu & Layar Game Over / Victory
- Animasi semburan api roket (*Thruster Particles*)
- Animasi pendaratan otomatis melambat di permukaan Bulan
- Efek ledakan partikel (*Explosion FX*) saat tabrakan
- Struktur modular OOP & siap dimainkan via Maven JavaFX Plugin

## Cara menjalankan project via Terminal/CMD:
```bash
mvn javafx:run
```
